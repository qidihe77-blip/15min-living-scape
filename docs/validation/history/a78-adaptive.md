# A78 方向补点与Walking加速

地点：康都世纪花园，原分析 `fa-89a32bfd-1baa-4de6-bac2-46d057770db4`。2026-10-16实测，数据见 [metrics.json](metrics.json)、[cache-replay.json](cache-replay.json)。保持80m/min、1200m/900s、重点1km、六类评分及200m盲区算法。原评分67.85714285714286、可达设施51处不变。

## 根因与修改

1. **43个采样单条OD**：旧实现无条件启动36方向真实路径及有限重试/修复，即便108个Matrix成本已足够。当前1km圈已复用径向成本模型，这些旧路径不是必需。新实现成功时只取Matrix；权限/预算/测量失败时惰性启动原单条回退。
2. **缓存0%**：旧客户端及路线缓存只有进程内5分钟TTL，重启失效；首次冷分析自然为0%，历史页面回放、UID去重与routeMemo也不在旧命中率分母内。新成功成本/真实几何缓存默认24小时落盘，六位BD-09坐标、方向、实际导航策略、终点UID、API来源共同组成OD键。坐标起点不受无效社区UID影响，地铁不同入口不能合并，反向OD不能合并，成本不能满足路径请求。失败不持久化；并发相同OD只计一次上游请求；取消信号隔离保留。
3. **预取未运行**：旧条件要求“全体候选+80≤初始220”，174候选被整体拒绝。优化只启动有界前40个有效候选、保留80余量，与独立Matrix队列重叠。既有UID去重、检索窗口距离预筛及最终端点绑定保留，外围POI没有被删除。
4. **没有把POI请求全部替换成矩阵**：矩阵不返回真实路径；174个设施都需要真实路径。对同一设施先Matrix再单条会重复消耗OD。本轮把批量接口用于成本采样及补点，保留设施真实路径请求，并优先查持久缓存。

官方接口依据：[Walking Matrix](https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout-walk)、[配额按输出路线数计](https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout)、[Walking路径与步骤](https://lbsyun.baidu.com/docs/webapi?title=directionv2%2Fwebservice-direction%2Fwalking)。批次≤10输出OD、滚动10 OD/s、日额度与有效期仍由现有服务授权限制。没有提高并发配额。

## 自适应边界

按真实Walking≤1200m且PIP在圈外的有效绑定POI，聚合到原10°区间；优先选择180m邻域内较密集的空间簇，以簇内中位方位补点，每原区间最多加一个方向，避免远处孤立点拉偏同区间选角。每新增方向沿用原2340m上界、三轮二分和同版本径向成本外推。新增点全部来自真实径向测量，不把POI坐标放进边界，不平滑。

默认≤18 OD（≤6方向）；本地点选4方向、12真实OD、3次HTTP、2.048秒。新增半径不得超过相邻最大半径250m或绝对1260m，面积增长上限12%，收缩上限2%。检查闭合、自交、起点、原1km圈嵌套、已有可达点丢失及已知超时点新增误包；失败整体回退原36圈。地图、POI空间诊断及面积计算使用同一新GeoJSON，原36模型单独保留用于回退与既有1km圈。

## 回退、测试与复现

- `WALKING_ACCELERATION_ENABLED=false`：恢复旧缓存及采样/预取行为。
- `ADAPTIVE_DIRECTIONS_ENABLED=false`：恢复原36圈；存档包含`baseGeojson`，刷新后同样按配置恢复。
- `ADAPTIVE_DIRECTION_OD_BUDGET=0`：不新增测时；TTL配置`WALKING_CACHE_TTL_SECONDS`默认86400。
- Matrix授权到期后只允许复用仍在TTL内的真实观测；缓存未命中由原额度闸门拒绝，再按既有单条Walking回退处理，不发起过期Matrix调用。
- `node scripts/benchmark-walking-a78.mjs --input=自己的完整分析JSON`：只读离线审计。
- 添加`--live`：一次有限实测，复用现有AK、有效期、10 OD/s及同一持久日额度账本；不调用Place，输出真实观测。不能同时从多个进程执行实测。
- `node scripts/replay-walking-cache-a78.mjs`：严格无网络缓存重载复核，需要本机对应缓存及保存基线。
- `node scripts/apply-a78-saved-refinement.mjs`：只重放已经保存的补点结果、检查目标坐标绑定、生成带SHA的可回退存档，不新增Walking。

维护测试覆盖：OD方向/入口/来源隔离、六位坐标、TTL与进程式重载、几何缓存能力、并发计数、健康Matrix无冗余单条及失败回退、补点预算/真实方向/原点保留、误包和异常退回、存档回退。界面仍为现有样式，无新按钮。
