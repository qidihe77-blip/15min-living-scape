# A83：盲区仅六大类，卡片仅两种结果

日期：2026-10-16。当前页面：`http://127.0.0.1:4173/?ui=a83&analysis=fa-01a23537-ee50-4105-a7cb-3bfbc6d009d0`。

## 实施范围

- 仅教育、医疗、商业、交通、养老、休闲参与盲区计算。移除三个重点设施专项模型、专项网格分支与目标描述；历史专项轮廓不会混入地图联合灰面、边界、悬停或面积统计。
- 六大类仍使用原整类无设施资格、200m网格、四邻接、Marching Squares、检索支撑、轮廓约束及灰色图层。图例仍统一显隐，条形图和重点服务卡片只保留原POI/路线联动。
- 菜市场、药店、小学原有1km Walking统计、独立检索证据和最近路线选择保留，不再生成专项空间盲区。
- 右侧仅展示：绿色100%“无盲区”；或真实盲区百分比。初始化、异常及无法计算时暂不展示卡片，删除占位、错误或其他状态文字，不将缺数据伪造为无盲区。
- 六大类、18小类、36方向边界、80m/min、评分与1km标准保持不变。

## 武汉实际记录

地点：湖北省武汉市汉阳区汉阳大道532号东北方向50米，碧溪苑小区二期。

| 项目 | 最终结果 |
| --- | --- |
| 盲区计算模型数 | 6，仅大类 |
| 实际地图盲区 | 养老 |
| 养老轮廓面积 | 68,223.273898m²，与移除专项前相同 |
| 卡片盲区面积 | 0.068km² |
| 卡片盲区面积占比 | 17.1%，分母沿用现有可判定域 |
| 15分钟圈总面积 | 0.978km²，独立展示，不替换可判定域分母 |
| 灰色条形悬停 | 仅“养老17.1%” |
| 绿色条形悬停 | 无提示 |
| API新增请求 | Place 0、Walking 0 |

旧版菜市场与养老曾因相同有效支撑网格得到完全相同轮廓。当前菜市场不参与盲区，地图和卡片均不会出现“菜市场＋养老”。这不影响菜市场作为商业小类计分或1km重点服务卡片。
