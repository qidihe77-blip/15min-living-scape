## 首轮失败与修复

1. 首轮维护回归678/683，5项旧断言与已授权的V8.6养老兜底归类冲突。更新为确认养老归养老院，并保留1200m等号、超距、失败、去重和排除误命中的严格检查。没有改变科学计算逻辑。
2. 无AK HTTP脚本最初继承本地采样开关且子进程已退出，等待逻辑不正确；显式隔离授权开关并修复退出等待，11项通过。
3. 浏览器首轮在异步图层尚未绘制时读取visible产生失败；改为等待真实绘制状态，干净副本19项通过，没有修改UI来绕过断言。
4. 旧八类HTTP核验引用已不存在的categories变量，退役返回410，不消费API。当前六类主链、评分和200m内核不变。
